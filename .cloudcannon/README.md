# Editing this site

Welcome! This is the AstroWind marketing site. Here's how the content is organised in CloudCannon.

## Pages

Most pages are built from **sections** — reusable blocks like heroes, feature grids, stats, pricing tables, testimonials and calls to action. Open a page in the **Visual Editor** to see the live page, then click a section to edit its text and images, or use the section list to add, reorder and remove sections.

- [Pages](cloudcannon:collections/pages) — the main site pages (Home, About, Services, Pricing, Contact).
- [Homepages](cloudcannon:collections/homes) — the alternate homepage demos (SaaS, Startup, Mobile App, Personal).
- [Landing pages](cloudcannon:collections/landing) — focused campaign pages.
- [Legal](cloudcannon:collections/legal) — Privacy Policy and Terms, edited as plain documents.

When you create a **new** page, it opens on an existing page as a temporary preview until it has been saved and published.

## Blog

- [Blog](cloudcannon:collections/post) — articles. Create and write new posts in the content editor. You can drop in **YouTube**, **Vimeo**, **Tweet** and **Logo** blocks from the toolbar.

## Site data

- [Site data](cloudcannon:collections/data) — the **navigation** file controls the header menu, footer link columns, social links and footer note. Edit it to change what appears in the site's menus.

## Tips

- Text fields that show a formatting toolbar accept **bold**, _italic_ and links.
- Image fields open the image picker — uploaded images are optimised automatically.
- The small "anchor" field on a section lets you link to it from a menu (e.g. an anchor of `features` is reachable at `/#features`).
